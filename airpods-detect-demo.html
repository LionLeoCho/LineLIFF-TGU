🎧 掃描 AirPods 觸發特效

使用前請先到 Teachable Machine 訓練模型:
1. 開啟 teachablemachine.withgoogle.com → Image Project
2. Class 1 命名「airpods」:上傳 20~30 張 AirPods 照片(不同角度/背景)
3. Class 2 命名「background」:上傳 20~30 張沒有 AirPods 的環境照
4. Train → Export Model → Upload (shareable link)
5. 把得到的網址貼到本檔案的 MODEL_URL

🔍 掃描中…把 AirPods 放進畫面
🎧✨
偵測到 AirPods Pro!
